# Davranış Kuralları

Bu repo hard Türk mizahı üreten bir skill içerir (küfür, kara mizah, roast).
İçerik kuralı skill çıktısı için geçerli, katkı sağlayanlar için değil.

## Beklenen davranış

- Issue/PR'larda saygılı ol. Reaction içeriği sert olabilir, katılımcı
  iletişimi sert olmak zorunda değil.
- Yeni kaynak önerirken gerçek içerik referansı ver, uydurma/asılsız iddia
  önermeyin.
- Teknik tartışmaya odaklan: kaynak uygunluğu, davranış kuralı netliği.

## Kabul edilmeyen davranış

- Hedefli taciz, nefret söylemi, gerçek kişilere yönelik zarar verici içerik
  önerisi.
- Siyasi gaf meme'lerini propaganda/yönlendirme amaçlı kullanma önerisi
  (bkz. `turkmeme/SKILL.md` Ton bölümü — zaten skill kuralıyla yasak).
- Spam PR, alakasız değişiklik.

## Raporlama

Sorun varsa GitHub issue aç. Repo sahibi değerlendirir.
